# Daemon System — Enhancements (Aprimoramentos) Catalog

> Companion document to [`daemon-system-rules-reference.md`](./daemon-system-rules-reference.md).
> That file keeps a curated excerpt of Enhancements from the **Módulo Básico** (the ones the prototype
> is actually expected to touch). This file is a broader **catalog of every Enhancement name found
> across the Sistema Daemon line** (basic module + all published sourcebooks/netbooks), gathered for
> reference and future scoping — most entries here are **not** candidates for prototype implementation,
> since they belong to settings (Trevas, Arkanun, Abismo, Supers RPG, Mítica, Invasão, etc.) outside the
> basic module this spike is grounded in.
>
> Source terms are Brazilian Portuguese, matching the original rulebooks.

---

## 1. Already in the prototype's rules reference (Módulo Básico)

These are covered with full cost/effect text in `daemon-system-rules-reference.md` §10 and are the
only Enhancements currently considered "in scope" for this spike: Afinidade com fadas, Alma Pura,
Ambidestria, Armas de Fogo, Arma ou Amuleto Mágico, Biblioteca, Bom Senso, Conhecimentos Arcanos,
Contatos e Aliados, Familiares, Guardião de Artefato, Homúnculo, Imunidade a Venenos, Inocência,
Pactos, Recursos e Dinheiro, Sábio, Saúde de Ferro, Sedutor, Sensitivo, Senso de Direção, Senso
Numérico, Sentidos Aguçados, Sono Leve, Sortudo, Talento.
